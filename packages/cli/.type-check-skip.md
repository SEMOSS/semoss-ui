# TypeScript Type Checking Issues

Currently skipping strict type checking for TUI components due to module resolution issues with ink.

The packages are installed but TypeScript cannot resolve them. This is likely due to:
1. ESM/CJS interop issues
2. Module resolution strategy (node vs nodenext vs bundler)
3. pnpm workspace symlink structure

## Workaround
Build with --skipLibCheck or use @ts-ignore for now.
