# Visual Rule Builder

A React application for building and managing visual rules with an intuitive interface.

## Development

```bash
# Install dependencies (from root)
pnpm install

# Start dev server
pnpm dev

# Build for production
pnpm build

# Run tests
pnpm test
```

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS v4
- Shadcn UI
- React Router
- MobX
