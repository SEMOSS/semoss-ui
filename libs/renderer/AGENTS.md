# AGENTS.md - @semoss/renderer

This document provides context for AI coding assistants working with the SEMOSS renderer
library.

> **Inherits from:** [../../AGENTS.md](../../AGENTS.md) for code style, file-naming, package
> structure, commit messages, Biome config, and Node/pnpm requirements.

## Overview

`@semoss/renderer` renders SEMOSS app / insight **block JSON** into a live UI. It provides the
block engine and the built-in block/cell definitions (grids, ECharts visualizations, PDF
viewer, inputs, etc.) that apps compose at runtime.

Primary exports: `RendererEngine` and `Blocks` (the block runtime), `DefaultBlocks` /
`block-defaults`, `cell-defaults`, and the pre-canned `renderer` entry.

## Build System

- **Bundler**: Rollup → ES modules (`dist/index.mjs`) with types in `dist/types/`.
- `./version` is exported directly from source (`src/version.ts`).

### Commands

| Command | Description |
|---------|-------------|
| `pnpm dev` | Watch mode (`rollup -w -c`) |
| `pnpm build` | Production build |
| `pnpm build:dev` | Development build |
| `pnpm test` | Run tests once (Vitest) |
| `pnpm test:watch` | Tests in watch mode |
| `pnpm test:ui` | Vitest UI |
| `pnpm test:coverage` | Coverage report |

## Structure

Follows the standard `src/` layout from the root AGENTS.md (a library, so no `pages/` or
router):

| Folder / file | Purpose |
|---------------|---------|
| `assets/` | Images and static files |
| `components/` | `blocks/`, `block-defaults/`, `cell-defaults/`, `shared/` — the block system |
| `contexts/` | React contexts (`<name>.context.tsx`) |
| `hooks/` | React hooks (`use-<name>.ts`) |
| `store/` | State (note: this lib currently uses singular `store/`; new stores follow `<name>.store.ts`) |
| `types/` | TypeScript types (`<name>.types.ts`) |
| `utility/` | Utility functions |
| `testing/` | Test helpers/fixtures |
| `renderer.tsx` | Pre-canned renderer entry component |
| `version.ts` | Package version (exported via `@semoss/renderer/version`) |
| `index.ts` | Main barrel — **curated**, be mindful of what is exported |

## Key Dependencies

- `mermaid` — diagram rendering
- `echarts-wordcloud` — word-cloud charts (ECharts extension)
- `dayjs`, `lucide-react`

## Agent Guardrails

### Do Not Modify

- **`dist/`** — build output, regenerated by Rollup.

### Be Cautious With

- **`src/index.ts`** — the public surface is intentionally curated (the file header says "BE
  MINDFUL OF WHAT WE EXPORT"). Only export what consumers truly need.
- **`rollup.config.js`** — build configuration.
- **Block/cell definition contracts** — apps depend on their shapes at runtime.

### When Adding a Block or Cell

1. Add it under `components/block-defaults/` or `components/cell-defaults/` following the
   existing block pattern and root naming rules.
2. Export it from the relevant barrel and, if public, from `src/index.ts`.
3. Verify the build:
   ```bash
   pnpm --filter @semoss/renderer build
   ```

### Testing Changes

```bash
pnpm --filter @semoss/renderer test
pnpm --filter @semoss/renderer build
```
